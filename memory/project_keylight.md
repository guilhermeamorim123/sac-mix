# Keylight

SaaS do Guilherme em `keylight.com.br`. Gera **8 imagens de anúncio prontas** a partir de fotos do produto enviadas pelo seller, em ~2 minutos. Otimizadas para Mercado Livre, Shopee e Amazon.

**Público:** sellers de e-commerce que não têm designer nem verba pra contratar um.

**Posicionamento:** "Designer é caro, Canva toma seu tempo."

**Entrega por geração:** hero shot, close-ups, foto de uso, cards de FAQ. Permite customizar cor de marca, logo, estilo visual e tom de voz. Não inventa elementos — usa as fotos reais enviadas.

**Planos (recorrente mensal):**

|-------|-------|----------|

## Programa de afiliados

Rodando na **Kiwify**. Link de afiliação:
`https://dashboard.kiwify.com/join/affiliate/JWsnB4vL`

**Status (ago/2026):** em fase de recrutamento de afiliados. Percentual de comissão ainda não definido/informado.

**Ângulo de recrutamento definido:** comissão **recorrente** é o argumento mais forte — afiliado ganha todo mês enquanto o cliente mantém a assinatura, diferente de infoproduto de venda única.

**Perfil de afiliado ideal** (não é o afiliado genérico de grupo de Telegram): quem já fala com seller — consultor de Mercado Livre/Shopee, gestor de tráfego de e-commerce, criador de conteúdo sobre "como vender no ML".
